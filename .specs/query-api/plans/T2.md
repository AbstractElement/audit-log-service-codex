# T2 — Application value types: `AuditEventCursor`, `AuditEventPage`, `AuditEventQuery`

*Add the new Application-layer types as pure records, not yet wired into any caller.*

## Why this task exists

The new query API needs three application-layer value types that are
deliberately shared across the boundary between the API layer and the
Infrastructure adapter, while staying framework-free:

- `AuditEventQuery` — the validated request shape that flows in.
- `AuditEventPage` — the paginated response envelope that flows out.
- `AuditEventCursor` — the opaque continuation token that re-pins the
  filter set across pages.

Per AC-5.1 these all live under `com.auditlog.application` so the API layer
only sees the opaque `String nextCursor`, never the cursor record itself.
T8 will lock that invariant with an ArchUnit rule.

This task is **pure addition**. No production caller references the new
types yet — that wiring is split across T3 (validation),
T4 (`findPage` port), T5 (`queryPage` service), T6 (API). Landing the types
on their own first means each subsequent PR is a single concern, and a
revert of any later task leaves these records harmlessly unused.

## Requirements covered

- **AC-2.1** (Ubiquitous) THE SYSTEM SHALL return a JSON envelope of the form
  `{ "items": [...], "nextCursor": <string|null>, "hasMore": <boolean> }`.
- **AC-2.8** (Ubiquitous) THE SYSTEM SHALL produce an opaque, URL-safe
  `nextCursor` string (callers must not parse it).
- **AC-5.1** (Ubiquitous) THE SYSTEM SHALL define cursor and request types in
  the Application layer; the API layer SHALL only translate HTTP
  ↔ Application DTOs.

## Design references — extracts inlined

### Cursor format

Opaque base64-url of a small JSON envelope:

```jsonc
{
  "ts":       "2026-05-03T14:22:09.871Z",
  "id":       "5b9c…-uuid",
  "actor":    "svc:billing",      // null if not in original filter
  "resource": null,
  "from":     "2026-04-26T00:00:00Z",
  "to":       "2026-05-03T00:00:00Z",
  "v":        1                    // schema version for forward compat
}
```

- **Encoding**: `Base64.getUrlEncoder().withoutPadding().encodeToString(json)`.
- **Decoding**: `400` on any parse error or unknown `v` (AC-2.5).
- **Tampering**: not signed in v1.
- **Pinned filters**: every cursor request decodes the envelope and reapplies
  `actor`, `resource`, `from`, `to` from inside it.

### API contract → Response

```jsonc
{
  "items":      [ { "id": "…", "timestamp": "…", "actor": "…", "action": "…",
                    "resource": "…", "outcome": "…", "context": { … } } ],
  "nextCursor": "eyJ0cyI6Ij…",
  "hasMore":    true
}
```

`hasMore == (nextCursor != null)` (AC-2.2). Items ordered
`event_timestamp DESC, id DESC`.

### Integration with arch layers → Application layer (Records / value types)

```
Application layer  (com.auditlog.application)
  AuditEventQuery       (validated request)
  AuditEventCursor      (ts, id, filters, version)
  AuditEventPage        (items, nextCursor, hasMore)
```

  `(UUID id, Instant timestamp, String actor, String action, String resource,

  `ObjectMapper` instance inside `AuditEventCursor`.

## Implementation plan

1. **Create `AuditEventQuery`.**
   - Path: `src/main/java/com/auditlog/application/AuditEventQuery.java`.
   - Signature:
     ```java
     public record AuditEventQuery(
         String actor,
         String resource,
         Instant from,
         Instant to,
         int limit,
         String cursor
     ) {
       // No cross-field validation in the ctor — T3 adds validate().
       // Nulls are allowed for every field except limit (a primitive).
     }
     ```
   - Add a small instance helper that T5 will use:
     ```java
     public AuditEventQuery withFilters(String actor, String resource,
                                        Instant from, Instant to) {
       return new AuditEventQuery(actor, resource, from, to, this.limit, this.cursor);
     }
     ```
   - **Edge case**: do not default `limit` to 100 here. That's an API-layer
     concern (T6); inside `AuditEventQuery` `limit` is always explicit.

2. **Create `AuditEventPage`.**
   - Path: `src/main/java/com/auditlog/application/AuditEventPage.java`.
   - Signature:
     ```java
     public record AuditEventPage(
         List<AuditEventView> items,
         String nextCursor,
         boolean hasMore
     ) {
       public AuditEventPage {
         items = List.copyOf(items);          // defensive copy → immutable
         if ((nextCursor != null) != hasMore) // AC-2.2 invariant
           throw new IllegalArgumentException(
             "hasMore must equal (nextCursor != null)");
       }
     }
     ```
   - **Edge case**: compact ctor enforces `hasMore == (nextCursor != null)`
     so a buggy caller cannot ship a malformed envelope.

3. **Create `AuditEventCursor`.**
   - Path: `src/main/java/com/auditlog/application/AuditEventCursor.java`.
   - Signature:
     ```java
     public record AuditEventCursor(
         Instant ts,
         UUID id,
         String actor,
         String resource,
         Instant from,
         Instant to,
         int v
     ) {
       public static final int V = 1;

       private static final ObjectMapper MAPPER = new ObjectMapper()
           .registerModule(new JavaTimeModule())
           .disable(SerializationFeature.WRITE_DATES_AS_TIMESTAMPS);

       public static String encode(AuditEventCursor c) {
         try {
           byte[] json = MAPPER.writeValueAsBytes(c);
           return Base64.getUrlEncoder().withoutPadding().encodeToString(json);
         } catch (JsonProcessingException e) {
           throw new IllegalStateException("cursor encode failed", e);
         }
       }

       public static AuditEventCursor decode(String token) {
         byte[] json;
         try {
           json = Base64.getUrlDecoder().decode(token);
         } catch (IllegalArgumentException e) {
           throw new IllegalArgumentException("INVALID_CURSOR", e);
         }
         AuditEventCursor c;
         try {
           c = MAPPER.readValue(json, AuditEventCursor.class);
         } catch (IOException e) {
           throw new IllegalArgumentException("INVALID_CURSOR", e);
         }
         if (c.v() != V)
           throw new IllegalArgumentException("INVALID_CURSOR");
         return c;
       }
     }
     ```
   - **Edge case — Spring leakage.** `ObjectMapper` lives in
     `com.fasterxml.jackson` (Jackson, not Spring). That is acceptable in
     the Application layer (the AGENTS.md rule forbids *Spring/JPA*, not
     library dependencies). Confirm `ArchitectureRulesTest` does not
     explicitly ban Jackson; the existing rules ban `org.springframework.*`
     and `jakarta.persistence.*` only.
   - **Edge case — padding.** Use `Base64.getUrlEncoder().withoutPadding()`
     to keep tokens compact and URL-safe; `Base64.getUrlDecoder()` accepts
     both padded and unpadded input.
   - **Edge case — version mismatch.** Any `v != 1` is treated identically
     to malformed input; both surface as `INVALID_CURSOR` (AC-2.5).

4. **Write the cursor unit tests.**
   - Path: `src/test/java/com/auditlog/application/AuditEventCursorTest.java`.
   - JUnit 5 + AssertJ (matching the existing test style under
     `src/test/java/com/auditlog`).
   - Test methods:
     - `encode_then_decode_roundTrip_preservesAllFields` — populate every
       field, encode, decode, assert equality via `Record.equals`.
     - `encode_then_decode_roundTrip_preservesNullFilters` — `actor` and
       `resource` null, others populated.
     - `decode_rejectsMalformedBase64` — pass `"!!not-base64!!"`; expect
       `IllegalArgumentException` with message `"INVALID_CURSOR"`.
     - `decode_rejectsVersionMismatch` — handcraft a JSON with `"v": 2`,
       base64-encode, decode → `IllegalArgumentException`.
     - `decode_rejectsNonJsonPayload` — base64-encode `"not json".getBytes()`;
       decode → `IllegalArgumentException`.
   - **Edge case**: assert on the exception's `getMessage()` *or* on a
     dedicated marker, but pick one and stay consistent so T6's exception
     handler can rely on the same hook.

5. **Run the unit suite for the new test.**
   - `./gradlew unitTest --tests AuditEventCursorTest` — green.

6. **Confirm ArchUnit still passes.**
   - `./gradlew archUnitTest`. The new files all sit under
     `..application..`, so no rule fires. (T8 will add the *specific*
     rule pinning `AuditEventCursor` to that package, but the existing
     framework-leak rule should already be enough to catch a mis-placed
     file.)

7. **Confirm no production code references the new types yet.**
   - `grep -rn 'AuditEventCursor\|AuditEventPage\|AuditEventQuery' src/main/java | grep -v '/application/'`
     must return empty. (Hits inside `application/` are fine — the records
     reference each other.)
